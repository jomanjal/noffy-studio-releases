# 노피 스튜디오 설치·시작 안내

노피 스튜디오는 웹소설의 설정집, 로드맵, 초고, 퇴고를 한곳에서 다루는 Windows 앱입니다. 원고는 선택한 작업 폴더에 파일로 저장됩니다. 첫 제공 대상은 Windows용 x64 설치본이며 macOS는 포함하지 않습니다.

## 설치와 라이선스 등록

1. 펀딩 창작자가 안내한 공식 배포 페이지에서 `NOFFY-Studio-Setup-<버전>.exe`를 받습니다. 다른 사람이 재배포한 파일은 사용하지 마세요.
2. 설치 파일을 실행해 설치 위치를 고릅니다. 이번 펀딩 설치본에는 Windows 코드 서명이 없어 ‘알 수 없는 게시자’ 또는 Windows의 실행 확인 경고가 나올 수 있습니다. 받은 곳과 파일 이름을 확인하세요. 출처가 다르거나 악성 파일 탐지 경고라면 실행을 중단하고 문의해 주세요. 백신을 끌 필요는 없습니다.
3. 앱을 열고 전달받은 라이선스 키를 붙여 넣어 등록합니다. 이 키는 앱 사용 권한이며 AI 이용권과는 별개입니다. 등록 후 라이선스 확인은 오프라인으로 이루어집니다.
4. 작품과 노트를 저장할 작업 폴더를 고릅니다. 앱 설치 폴더와 다른 곳에 두고, 이 폴더를 주기적으로 백업하세요.

라이선스 키는 비공개로 보관하세요. 제공 수량과 이용 조건은 후원한 선물의 안내를 따릅니다. PC를 바꿨을 때 다시 등록할 수 있도록 전달받은 키를 별도로 보관하세요.

## AI 연결

AI 없이 직접 쓰기부터 시작할 수 있습니다. AI 생성을 사용할 때는 작업 폴더를 연 뒤 **설정 → AI**로 이동합니다.

- **구독 AI 앱**: 사용할 AI 앱을 설치하고 로그인한 상태에서 목록의 **연결**을 누르고 확인합니다. 연결을 마친 뒤 해당 AI 앱을 새로 여세요. ‘연결됨’은 연결 설정이 등록됐다는 뜻이며, 실제 생성에는 해당 서비스의 이용권과 사용 한도가 적용됩니다.
- **API 키**: 사용하는 제공자의 API 키를 저장하고 역할별 모델을 고릅니다. API 이용료는 앱 구매와 별도이며 제공자에게 부과될 수 있습니다.

AI를 호출하면 생성에 필요한 기획·설정·원고 일부가 선택한 AI 서비스로 전달됩니다. 해당 서비스의 데이터 처리 조건을 확인한 뒤 사용하세요. 라이선스 키나 API 키를 원고·기획에 넣지 마세요.

연결이 잘 안 되면 AI 앱의 설치·로그인 상태를 확인하고 **다시 연결**한 뒤 새로 여세요. 연결 설정만으로 모든 서비스의 모델 사용 권한이 생기는 것은 아닙니다.

## 첫 작품

새 작품에서 기획을 입력하고 설정집을 만듭니다. 설정집을 확인한 뒤 로드맵을 만들고, 다음 화의 초고를 받거나 직접 씁니다. AI가 만든 설정·사건·원고는 작가가 확인하고 고칩니다. 생성이 끝나면 원고가 저장됐는지 확인하세요.

## 업데이트

앱을 시작하면 새 버전을 확인합니다. 새 버전이 있을 때 화면에 **업데이트 다운로드** 버튼이 나타납니다.

1. 버튼을 누르면 다운로드합니다. 받는 동안 계속 작업할 수 있습니다.
2. 다운로드가 끝나면 **종료할 때 업데이트 설치**를 눌러 설치를 예약합니다. 누르지 않으면 설치하지 않습니다.
3. 원고를 저장하고 저장 완료를 확인한 뒤 앱의 모든 창을 평소처럼 종료합니다. 종료 후 새 버전을 설치하며, 앱을 강제로 다시 시작하지 않습니다.
4. 종료 전에는 **설치 예약 취소**로 미룰 수 있습니다.

업데이트 확인이나 다운로드에 실패해도 작업은 계속할 수 있습니다. 연결을 확인한 뒤 **다시 확인**을 누르세요. 자동 갱신이 계속 실패하면 원고를 백업하고 앱을 종료한 뒤 공식 배포 페이지의 새 설치 파일을 받아 갱신할 수 있습니다.

업데이트는 백업을 대신하지 않습니다. 작업 폴더는 별도 장치에도 복사해 두세요. 설치 폴더에 원고를 넣지 마세요. 설정은 이 PC의 앱 데이터에 저장되며, 다른 PC로 옮긴 API 연결은 다시 설정해야 할 수 있습니다.

## 문의

펀딩 페이지의 창작자 문의로 앱 버전, 문제가 발생한 순서, 화면의 오류 문구를 알려 주세요. 설정의 앱 정보에서 진단 정보를 복사할 수 있습니다. 라이선스 키·API 키·비공개 원고 전체를 문의 글이나 공개 화면에 올리지 마세요.
