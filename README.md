# 노피 스튜디오 0.1.1 설치·시작 안내


Windows 10·11 x64 및 macOS 15 이상(Apple Silicon·Intel)용 설치본입니다. 원고와 노트는 직접 고른 작업 폴더에 저장됩니다.


[환경별 설치 파일과 사용 가이드 PDF](https://github.com/jomanjal/noffy-studio-releases/releases/latest)

## Windows 설치와 등록


1. 창작자가 안내한 공식 배포처에서 `NOFFY-Studio-Setup-0.1.1.exe`를 받습니다.
2. 설치 파일을 실행합니다. 이번 펀딩 버전은 Windows 코드 서명이 없어 ‘알 수 없는 게시자’ 또는 SmartScreen 안내가 나올 수 있습니다. 공식 배포 파일인지 확인한 뒤 ‘추가 정보 → 실행’으로 진행할 수 있습니다. 악성 파일 탐지 경고나 조직의 보안 차단은 별개이며, 백신을 끌 필요는 없습니다.
3. 인터넷에 연결한 상태에서 앱에 전달받은 짧은 등록키(`NF-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX`)를 입력합니다. 별도 인증 사이트 방문이나 ChatGPT 로그인은 필요 없습니다.
4. 등록을 마친 PC에서는 정기 재인증 없이 오프라인으로 앱을 사용할 수 있습니다. AI 서비스에 필요한 인터넷·이용권·API 비용은 별개입니다.
5. 작업 폴더를 선택합니다. 원고는 `novels/<작품 폴더>/episodes/`의 Markdown 파일로 남습니다. 작업 폴더 전체를 별도 장치에도 백업해 주세요.


## Mac 설치와 등록

1. 위 다운로드 페이지에서 Mac 칩에 맞는 `mac-arm64.dmg`(M 시리즈) 또는 `mac-x64.dmg`(Intel)를 받습니다.
2. DMG를 열고 NOFFY Studio를 응용 프로그램 폴더에 복사한 뒤 실행합니다.
3. 이번 설치본은 개발자 서명·공증 없이 제공합니다. 첫 실행이 차단되면 공식 파일을 확인하고 [Apple의 실행 허용 안내](https://support.apple.com/ko-kr/102445)를 따라 주세요. 회사·학교의 보안 정책으로 실행이 제한될 수 있습니다. 보안 기능 전체를 끄지 마세요.
4. 인터넷에 연결해 전달받은 짧은 등록키를 입력하고 작업 폴더를 고릅니다. 이후 오프라인 편집이 가능합니다.

## 기기 관리


개인 사용권 하나로 Windows·Mac을 합쳐 본인 컴퓨터 총 두 대에 등록합니다. 앱의 **설정 → 정보·문제 보내기**에서 등록 기기를 확인하고 해제할 수 있습니다. 키를 다시 입력해야 하므로 비공개로 보관하세요.


기기 해제는 새 PC를 등록할 자리를 비우는 기능입니다. 이미 발급된 기존 PC의 오프라인 사용 권한이나 원고를 삭제하지 않습니다. 두 PC 사이 원고가 자동으로 동기화되는 기능은 아닙니다.


## 시작하기


AI 없이 직접 집필할 수 있습니다. AI를 사용하려면 **설정 → AI**에서 구독 AI 또는 API 키를 연결합니다. 다른 회사의 호환 서버는 주소·키·모델명을 직접 입력할 수 있습니다. 앱 구매에는 외부 AI 이용료가 포함되지 않습니다. AI 생성에는 필요한 설정과 원고 일부가 선택한 서비스로 전달됩니다.


## 업데이트


Windows는 새 버전이 있을 때 **업데이트 다운로드**를 눌러 받습니다. 다운로드 후 **종료할 때 업데이트 설치**를 선택하고 앱을 종료하면 갱신합니다. 설치를 예약하기 전에는 강제로 갱신하지 않습니다. 예약은 종료 전에 취소할 수 있습니다.


Mac은 앱의 새 버전 안내에서 DMG를 내려받고 앱을 완전히 종료한 뒤 응용 프로그램 폴더의 앱을 직접 교체합니다. 작업 폴더와 사용자 데이터를 삭제하지 마세요.

업데이트 오류가 나도 작업할 수 있습니다. 계속 실패하면 공식 배포처의 새 설치 파일로 갱신하세요. 갱신 전에 원고를 저장하고 작업 폴더를 백업해 주세요.


## 문의


텀블벅 창작자 문의로 앱 버전과 발생 순서, 오류 문구를 알려 주세요. 라이선스 키·API 키·비공개 원고 전체는 공개 글에 넣지 마세요.
